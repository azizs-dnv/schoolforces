# SchoolForces

SchoolForces is a programming contest platform for school students, featuring coding problems, contests, ratings, and leaderboards.

## Getting Started

Requires Node.js.

```bash
npm install
npm run dev
```

To create and preview a production build:

```bash
npm run build
npm run preview
```
