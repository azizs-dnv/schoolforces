# SchoolForces

SchoolForces — платформа для школьных соревнований по программированию с задачами, контестами, рейтингом и таблицей лидеров.

## Запуск локально

Требуется Node.js.

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```
